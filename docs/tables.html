Action Plan & Allocation Tables

This chapter reproduces the Action Plan Database project tables (Tables 7–9, Section 3.b) and the entity TN load allocation tables for the 2027–2031 implementation period (Tables 10–14, Section 3.f) exactly as they appear in the 2027 Reasonable Assurance Update. Click any table to enlarge.

These tables are reproduced as images from the submitted RA Update to preserve the exact entity names, allocation percentages, and load figures. The underlying project records live in the online Tampa Bay Action Plan Database; allocation figures derive from the tbep-tech/load-estimates pipeline and the Consortium’s entity-load workbooks.
