Code & Data Provenance

Code & data provenance

Every figure and table in this book is produced from the analysis code in tbep-tech/reasonable-assurance-analysis. The table below maps each deliverable to its source.

Figures 1, 4, 6, 8, and 9 are generated in this repository. Figure 2 is generated here (annual chl means all segments) and also appears reproduced from the submitted document. Figures 3, 5, 7, and 10 are reproduced as images from the submitted 2027 RA Update.

The compliance Tables 2–6 are rendered natively (flextable) in the Overview chapter from the final RA Update values. Appendices 1–5 are rendered natively from per-segment CSVs in data/ (appendix1_otb.csv … appendix5_rltb.csv), extracted from the TBEP load-reporting “Assessment” tables (drafttables.qmd → show_aaassess(), data/aa2225.RData), covering 2022–2025 (matching the final submittal period). The Action Plan / allocation Tables 7–14 are reproduced as images to preserve exact entity names and allocation figures; their data come from the tbep-tech/load-estimates pipeline, the Tampa Bay Action Plan Database, and the entity-load workbooks. Figure 11 (chlorophyll-a attainment grid) remains document-maintained.

Pipeline order

R/dat_proc.R      # assemble population, chlorophyll, LULC, seagrass, loading inputs -> data/
   |
   +--> R/figs.R  # Figures 1, 2, 4, 6, 8, 9 -> figs/ ; writes data/loadratios1985-2025.csv
   |
   +--> R/docs.R  # delivery-ratio table -> docs/loadratiotab1985-2025.docx

External dependencies

  • tbep-tech/load-estimates — annual TN/TP/hydrologic load estimates; Figures 7 & 10 and Table 1 source data
  • tbeptools — thresholds, segment averaging, RA plotting helpers
  • US Census Bureau ACS (via tidycensus) — Tampa MSA population
  • SWFWMD — land use / land cover and seagrass coverage mapping
  • FDEP — 303(d)/305(b) impaired-waters assessment categories
